# Báo Cáo Học Thuật - Đánh Giá Hiệu Năng Hệ Thống (CO3007)

Báo cáo Bài tập lớn: **Đánh giá Hiệu năng Hệ thống Bất đồng bộ dựa trên Lý thuyết Hàng đợi và Mô phỏng Sự kiện Rời rạc**.
- **Lớp:** L02 - **Nhóm:** SPE-L0x-008 - **Học kỳ:** HK261
- **Giảng viên hướng dẫn:** Thầy Nguyễn Phương Duy
- **Trường:** Đại học Bách Khoa - ĐHQG-HCM (HCMUT - VNU-HCM)

---

## 📄 Nội dung Báo cáo
- **File PDF hoàn chỉnh:** [`main.pdf`](main.pdf) (Biên dịch chất lượng cao 78 trang).
- **Mã nguồn LaTeX:**
  - `main.tex`: File tài liệu master.
  - `cover.tex`: Trang bìa chuẩn Bách Khoa (Khung viền đôi TikZ, logo HCMUT, bảng thành viên).
  - `sections/`: 5 chương nội dung chính, abstract và bảng phân công nhiệm vụ.
  - `image/`: Sơ đồ UML (Class & Sequence Diagram), sơ đồ trạng thái FSM và biểu đồ thực nghiệm.

---

## 🛠️ Hướng dẫn Biên dịch LaTeX sang PDF
Để biên dịch lại báo cáo từ mã nguồn:
```bash
pdflatex -interaction=nonstopmode main.tex
pdflatex -interaction=nonstopmode main.tex
```
File PDF xuất ra sẽ tự động cập nhật vào `main.pdf`.
